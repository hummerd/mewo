# MEWO sage sprout icon

The selected concept is `mewo-sage-sprout-concept.png`. The production foreground
is `../../app/src/main/res/drawable-nodpi/mewo_launcher_foreground.png`.
Both were made with the built-in image generation tool. Android applies its
launcher mask to the adaptive icon, with a separate sage background and a
transparent speech-bubble/sprout foreground. The notification small icon remains
a separate Android notification asset.
