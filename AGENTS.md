# MEWO (momora) project

## Essential Info

MEWO is Android mobile app for helping learning new languages. In particular this app
helps memorising words by sending user notifications with reminders.

## Current state

- Currently it is for learning hebrew.
- We memorising most popular words and phrases that are just hardcoded in predefined JSON.

## Spec driven

This project is spec driven. Always check SPEC.md for understanding what we are doing.
All major changes should first be described by human in SPEC.md. AI agents should not
modify it, until asked explicitly.
